## Q8. Build order recommendation, for you to confirm

You asked me to pick the order (Q4). The recommendation is **skeleton first**:
get a bare site live at the real URL with one post and one project page, then
fill in the About page, the real content, and the polish. The reason is that
publishing to a live URL is the step most likely to surprise you, and it costs
almost nothing to hit early. Value-first would build the nicest-looking
projects page before anything is publishable; risk-first is the same argument
as skeleton-first for this project, since publishing *is* the main unknown.

A. Confirm skeleton first
B. Value first instead — build the projects showcase properly before anything is live
C. Risk first instead — I'll name what I think the riskiest part actually is
X. Other (please specify)

[Answer]: A. Confirm skeleton first
